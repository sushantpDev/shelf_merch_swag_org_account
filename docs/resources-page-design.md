# Resources page design

The `/resources` hub follows the approved full-page concept, with the subsequent request for fully printed premium packaging. The typography uses `--font-family-public-sans`, the same token as the public catalog. The shared header, footer, existing team destinations and demo route are retained. Hub styles are scoped to `.resources-hub` so the individual team pages retain their existing design.
