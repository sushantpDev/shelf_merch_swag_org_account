# Apparel editorial assets

Generated with the built-in imagegen tool for the approved Apparel category mockup. These images are separate assets; page headings, captions, buttons and promotional copy are rendered as accessible HTML in `CatalogEditorialGrid.tsx` and `CatalogCategoryView.tsx`.

Existing T-shirt, polo and jacket editorial photos are reused. Category names and destinations come from the catalog taxonomy rather than the mockup's illustrative assortment.
